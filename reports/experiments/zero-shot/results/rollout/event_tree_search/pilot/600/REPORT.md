## 지표

mIoU=전체 query의 temporal IoU 평균, R@t=IoU≥t인 query 수/전체 query 수(t=.3/.5/.7), 높을수록 좋다. IoU=시간 교집합/합집합. Δ는 기존 greedy 대비이며 R의 변화는pp다. 실패는0점. decoder tokens는 seed 생성·공통 proposal/critic·search·최종 선택을 합산한 conceptual cost이며 exact cache reuse로 줄어든 실행 비용과 다르다. model seconds는 새 model operation의 cold-cache 측정 시간 합이고 공통 video prefill 및 과거 seed 생성 시간은 제외되어 latency로 직접 해석하지 않는다. 같은 token 상한이 같은 FLOPs를 뜻하지 않는다.

# Temporal mode search · pilot600 · 결과 보고서

상태: 실행 중·미완료. 고정600 query 중 0 query 완료. 세 데이터셋별200 query,3조건×3seed의 반복 선택은 query 수와 구분한다.

절대 하한0.9%,상대 계수0.01,누적 main 질량90%,예측을[0,D]로 clipping한다. main65,536/tail131,072/judge32,768 decoder input tokens이며 기존 제안 대비 분기 예산을 두 배로 늘렸다.

IoU=교집합/합집합,mIoU=전체 query의 평균 IoU,R@τ=IoU≥τ 비율(τ=.3/.5/.7). 높을수록 좋다. 실패는0점이며 각 query 안에서3seed를 평균한다. ΔmIoU는 동일 clipping greedy 대비 차이다. main oracle은 실제 main 후보의 GT 최고 IoU,pool oracle은 shortlist의 최고 IoU,diagnostic oracle은 main+tail의 사후 상한이며 실제 선택 성능이 아니다.

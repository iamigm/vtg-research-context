300 query 중 세 방법을 모두 완료한 query 161개. 고유 영상 292개. 조건 반복 수와 query 수를 구분한다. 완료 전 수치는 진행 중 공통 부분집합이며 전체 성능으로 해석하지 않는다.

## 후보 품질과 zero-shot 대비 차이

IoU=예측·GT 교집합 길이÷합집합 길이,mIoU=query별 IoU 평균,R@τ=IoU≥τ 비율이다. 높을수록 좋다. 괄호 안Δpp=100×(결과−같은 query의zero-shot greedy). Greedy는 동일 입력의 새 native generation이며 clipping·평가 정책도 같다. GT는 탐색 후 평가에만 사용한다.

## 해석 범위

현재 얻은 interval entropy·variance는 관측 유효 분포에 조건부다. 종료 시 남은 질량·context limit·정책 제외 질량을 함께 확인한다. Candidate oracle 향상이 최대 native-mass 답의 성능 향상을 의미하지 않는다. Novelty는 시간적 차이이며 사건 semantic이나 정답 여부를 판별하지 않는다.

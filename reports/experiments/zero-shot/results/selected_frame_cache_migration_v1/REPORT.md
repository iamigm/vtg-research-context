# 사용 프레임 공용 캐시 정리

두900개 실행과 통합보고 완료 후 정리했습니다. 입력·응답·계획·원본영상·전체PTS와 픽셀hash metadata는 보존했습니다. 모든 저장 계획이 요구하는 프레임을 공용캐시에 복사하고 검증한 뒤 기존 비압축 배열을 제거했습니다. 기존 metadata의 path는 이관 기록으로 연결되며 입력코드가 cache_key로 공용파일을 찾습니다. 새 계획이 추가 프레임을 요청하면 원본에서 디코딩하고 원래 픽셀hash와 대조해 확장합니다.

기존 배열 제거 856.0GiB, 공용 배열 574.4GiB. 참조를 확인하지 못한 캐시는 삭제하지 않았습니다.

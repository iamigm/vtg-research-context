# Pilot 누적 통합 · compute_cost/embedding_vs_generation_16fps

같은 실험 계열의 실제 등록된 pilot 단계만 표시한다. 질문 수와 모델·조건별 응답 수를 구분한다.

| 표본 범위 | 보고서 | 고정 manifest |
|---|---|---|
| pilot300 · 300질문 | [보고서](../300/REPORT.md) | 각 원보고서의 표본 선정 기록 참조 |

새600·900개 결과는 같은 계열의 pilot 아래 숫자 폴더에 추가하고 대응 artifacts/runs 경로를 함께 등록한다. 없는 단계의 결과를 만들지 않는다. 원자료를 복제하거나 겹치는 질문을 독립 표본처럼 합산하지 않는다. 다른 프로젝트의 pilot과 동일한 코호트라고 자동 가정하지 않는다.

중첩 단계가 여러 개면 각 고정 manifest의 질문 순서와 prefix 포함 관계를 검사한다. 설정·입력·생성 정책이 바뀌면 새 버전 계열로 구분한다.

## 2026-09-28T10:55:46.041Z — Codex final report

**첫 실험은 “임베딩 차이의 peak가 행동 구간의 시작·종료와 일치하는가?”로 잡는 것을 추천합니다.** 이후 query를 반영했을 때 경계가 더 잘 잡히는지 보면, MR에 쓸 수 있는 temporal signal인지 판단하기 좋습니다.

`/data/video/MR`을 확인해보니 세 데이터셋 모두 원본 영상과 `query`, `relevant_windows`, `video_path`가 포함된 annotation이 있습니다. 사전 계산된 임베딩은 없어 추출이 필요합니다.

**1. 데이터셋별 12개 영상으로 시작**

무작위 8개와 가설을 확인하기 위한 진단용 4개를 고르고, 두 그룹의 결과는 따로 보는 구성입니다. 동일 영상의 여러 query는 함께 확인합니다.

| 데이터셋 | 진단용 샘플 선정 기준 | 확인하고 싶은 것 |
|---|---|---|
| Charades-STA | 배경은 유지되면서 행동이 시작·종료되는 영상 | 장면 전환 없이도 행동 변화를 잡는가 |
| ActivityNet-Captions | 여러 행동 단계가 이어지는 영상 | 행동 단계의 전환과 지속 구간을 구별하는가 |
| QVHighlights | 컷 전환이 많거나 query에 해당하는 구간이 여러 개인 영상 | 편집 효과와 query 관련 변화를 구별하는가 |

QVHighlights는 한 query에 여러 구간이 대응할 수 있으므로, 첫 시작과 마지막 종료로 합치지 않고 각 구간을 유지해야 합니다. [데이터셋 논문](https://arxiv.org/abs/2107.09609)

처음에는 train에서 탐색하고, 유망한 설정만 별도 영상으로 검증하면 됩니다. ActivityNet에는 컨테이너 오류가 기록된 파일이 있어 샘플 선정 시 제외해야 합니다.

**2. 같은 임베딩으로 세 종류의 신호 비교**

우선 frozen 이미지 인코더 하나로 **2 FPS** 임베딩을 추출합니다. 이미지·텍스트가 같은 공간에 있는 CLIP 계열이면 query 조건부 실험까지 연결하기 편합니다.

정규화한 프레임 임베딩을 \(z_t\), query 임베딩을 \(q\)라고 하면:

| 신호 | 정의 | 가설 |
|---|---|---|
| 변화 크기 | \(d_t=1-z_t^\top z_{t-\Delta}\) | 큰 변화가 행동 경계와 대응한다 |
| 변화 벡터 | \(\delta_t=z_t-z_{t-\Delta}\) | 변화의 방향이 시작·종료 구분에 유용하다 |
| Query 관련성 변화 | \(g_t=q^\top\delta_t\) | 양수는 query 상태로 진입, 음수는 이탈하는 경향이 있다 |

\(\Delta\)는 **0.5초, 1초, 2초**로 비교합니다. 느린 행동은 인접 프레임 차이보다 조금 긴 간격에서 잘 드러날 수 있다는 가설입니다.

여기서 두 가지를 구분해야 합니다.

- **변화 크기만으로는 시간 방향을 알 수 없습니다.** 두 프레임의 순서를 뒤집어도 거리는 같습니다.
- \(g_t=q^\top z_t-q^\top z_{t-\Delta}\)이므로, query 유사도 곡선의 차분과 정확히 같습니다. 별도의 새 정보라기보다 기존 정보를 유용한 형태로 표현하는지 보는 실험입니다.

**3. 가장 먼저 해볼 실험: 경계 검출**

각 영상에 아래 정보를 같은 시간축으로 그립니다.

- 프레임 썸네일과 GT 구간
- 임베딩 변화 크기 \(d_t\)
- Query 유사도 \(s_t=q^\top z_t\)
- Query 관련성 변화 \(g_t\)
- 픽셀 차이와 컷 전환 위치

이렇게 보면 “큰 peak가 생겼는데 실제로는 카메라 컷이었다”, “배경은 같지만 행동 시작에서 query 관련성이 올라갔다”를 바로 구분할 수 있습니다.

수치로는 다음을 봅니다.

- **Boundary F1:** peak와 GT 경계를 ±1초, ±2초 허용 오차로 일대일 매칭.
- **경계 근처 대 내부:** 경계 부근에서 \(d_t\)가 더 큰지 영상별 비교.
- **컷 없는 경계 성능:** 컷과 겹치는 경계를 분리해도 효과가 남는지.

비교군은 동일한 개수의 무작위 peak와 픽셀 차이 peak입니다. 영상 시작·끝에 걸친 GT 경계는 별도로 처리합니다. Annotation의 구간 경계가 항상 명확한 시각적 변화인 것은 아니어서, 실패 사례도 함께 봐야 합니다.

**4. 가장 중요한 확장: MR 결과를 실제로 개선하는가**

경계와 상관관계가 있어도 검색에 도움이 된다는 보장은 없습니다. 같은 query 유사도 기반 구간 추출기에 다음 세 설정을 붙여 비교합니다.

| 설정 | 구간 추출에 사용하는 정보 |
|---|---|
| A | Query 유사도 \(s_t\) |
| B | \(s_t\) + 변화 크기 \(d_t\) |
| C | \(s_t\) + query 관련성 변화 \(g_t\) |

예를 들어 A가 찾은 구간의 시작·종료를 주변 ±2초 안에서 보정합니다. B는 변화 peak를, C는 시작에서 양의 변화와 종료에서 음의 변화를 활용합니다.

**예측은 annotation 없이 만들고**, 이후 temporal IoU와 시작·종료 오차를 비교합니다. GT 경계 근처에서 최적 peak를 고르는 방식은 실제 MR 개선 실험이 되지 않습니다.

- B만 좋아지면 일반적인 변화 신호가 유용할 가능성.
- C가 더 좋아지면 query 관련 상태 변화가 유용할 가능성.
- 컷이 많은 영상에서만 좋아지면 편집 경계에 의존할 가능성.

**5. 시간 방향까지 주장하려면 추가 검증**

문 열기/닫기, 앉기/일어서기처럼 방향이 있는 행동을 따로 모아 **변화 크기와 signed 변화 벡터**를 비교합니다. 단순히 영상 역순에서 \(\delta_t\) 부호가 바뀌었다는 것은 정의상 당연한 결과여서 증거가 아닙니다.

확장 단계에서는 작은 probe로 행동 전환을 분류하되, 영상 단위로 분리해서 평가하고 다음을 비교하면 좋습니다.

\[
z_t,\quad [z_{t-\Delta},z_t],\quad \delta_t
\]

특히 두 프레임을 연결한 표현과 비교해야, 차분 표현의 이점인지 단순히 두 시점에 접근한 효과인지 알 수 있습니다.

**제가 우선 실행할 구성은 36개 영상 → 경계 시각화 → 컷을 분리한 경계 평가 → A/B/C 구간 보정 비교입니다.** 이 규모에서는 통계적 결론보다 성공·실패 패턴을 찾는 데 집중하고, 효과가 보이면 영상 수를 늘려 검증하는 게 좋겠습니다.

실제 MR 결과 개선까지 가지마 그냥 모델의 표현이 temporal 정보를 얼마나 담고 있는지 그게 써먹을만한지 알아보고 싶은 거야


## 2026-09-28T11:08:32.635Z — Codex final report

그러면 **MR 성능은 제외하고, frozen 모델의 표현에서 시간적 구조를 얼마나 읽어낼 수 있는지**를 보면 됩니다. “써먹을 만하다”는 기준도 **복잡한 학습 없이 거리나 작은 linear probe로 그 구조를 추출할 수 있는가**로 잡겠습니다.

특히 **시간적 근접성, 행동 변화, 진행 방향**을 나눠 보는 게 좋습니다. 가까운 프레임끼리 비슷하다는 사실만으로 행동의 순서까지 표현한다고 보기는 어렵습니다.

**1. 시간 간격이 임베딩 거리에 나타나는가**

같은 영상에서 다양한 간격의 프레임 쌍을 뽑습니다.

\[
D(t,\Delta)=1-\cos(z_t,z_{t+\Delta})
\]

- 간격: 0.5, 1, 2, 4, 8초.
- 시각화: 시간 간격별 거리 분포와 영상 내 전체 프레임의 similarity matrix.
- 지표: 시간 간격과 임베딩 거리의 영상별 Spearman 상관계수.

거리가 시간 간격에 따라 증가하면 **local temporal continuity**가 있다는 근거입니다. 반복 동작에서는 다시 가까워질 수도 있으므로, 단순한 단조 증가 여부와 반복 구조를 함께 봅니다. 컷을 가로지르는 쌍은 분리해야 합니다.

**2. 임베딩 차이가 행동 변화에 반응하는가 — 가장 먼저 추천**

\[
\delta_t=z_{t+\Delta}-z_t
\]

다음 세 상황에서 \(\|\delta_t\|\)와 변화 방향을 비교합니다.

| 상황 | 확인할 내용 |
|---|---|
| 같은 행동이 지속됨 | 변화가 비교적 작거나 일정한가 |
| 같은 장면에서 행동이 바뀜 | 변화량이나 방향이 달라지는가 |
| 행동 변화 없이 컷·카메라 이동이 발생함 | 외형 변화에 과도하게 반응하는가 |

기존 구간 annotation은 후보를 찾는 데 사용하고, 소수 샘플은 직접 확인해서 구분하는 게 좋습니다. **Query 구간의 경계가 곧 행동 전환 경계인 것은 아니기 때문입니다.**

결과는 변화량 분포, 효과 크기, ‘행동 지속 vs 전환’ AUROC 정도면 충분합니다. 픽셀 차이를 비교군으로 두면 임베딩이 단순한 화면 변화보다 의미 있는 정보를 주는지도 볼 수 있습니다.

**3. 변화 벡터가 ‘어떻게 바뀌었는지’를 담는가**

제가 가장 흥미롭게 보는 실험입니다. 서로 다른 영상에서 같은 전환을 찾아 변화 벡터를 비교합니다.

예를 들어:

- 앉기 ↔ 일어서기
- 문 열기 ↔ 닫기
- 물건 집기 ↔ 내려놓기

검증할 가설은 **같은 전환의 변화 벡터는 영상이 달라도 비슷하고, 반대 전환은 구별되는가**입니다.

- 학습 없이: 변화 벡터의 최근접 이웃이 같은 전환인지 확인.
- 작은 학습으로: linear probe로 전환 종류 분류.
- 비교 표현: \(z_t\), \(z_{t+\Delta}\), 두 임베딩의 연결, \(\delta_t\).
- 분할: 같은 영상이 학습과 평가에 함께 들어가지 않도록 구성.

두 임베딩의 연결과 비교하는 이유는, **차분이 정보를 추가하는 것은 아니지만 전환 정보를 더 쉽게 읽을 수 있게 만드는지** 확인하기 위해서입니다. 역순으로 만들어 부호만 바꾸는 실험은 이 가설의 증거가 되지 않습니다.

**4. 행동의 진행 정도를 읽을 수 있는가**

시작과 끝이 비교적 명확한 행동을 초반·중반·후반으로 나누고, 임베딩이나 변화 벡터로 단계를 구분해 봅니다.

- 행동 종류를 맞추는 대신 **같은 행동 안에서 진행 단계**를 구분.
- 영상 단위로 분리한 linear probe 사용.
- 프레임 번호나 timestamp는 입력에서 제외.
- 반복 행동은 별도 분석.

이 실험이 성공하면 경계 감지보다 강한 주장인 **행동 내부의 진행 상태가 표현에 담겨 있다**는 근거가 됩니다. 다만 마지막 자세 같은 정적인 단서로도 풀릴 수 있어, 이것만으로 동작 자체를 이해한다고 해석하지는 않습니다.

처음에는 **데이터셋별 10~15개 영상으로 1·2번을 수행하고**, 명확한 전환 사례를 모아 3번으로 확장하겠습니다. Charades-STA에서는 같은 배경 안의 행동 변화, ActivityNet에서는 행동 단계의 진행, QVHighlights에서는 컷에 대한 민감도를 중점적으로 보면 좋습니다.

그리고 해석에 중요한 전제가 하나 있습니다. **프레임별 이미지 인코더를 쓰면 ‘정적 표현의 시퀀스에서 시간 정보를 복원할 수 있는가’를 보는 것이고, 비디오 인코더를 쓰면 ‘모델이 입력의 시간 순서를 표현에 반영하는가’까지 볼 수 있습니다.** 후자는 같은 프레임 묶음의 원순서·역순·셔플 입력을 비교하는 실험을 추가하면 됩니다.

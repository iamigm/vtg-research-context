## 2026-10-21T01:40:34.513Z — Codex final report

아니요. **Qwen3는 텍스트 전용과 VL 모델이 별도로 구분됩니다.**

| 계열 | 모델 예시 | 입력 |
|---|---|---|
| **Qwen3** | `Qwen/Qwen3-8B` | 텍스트 |
| **Qwen3-VL** | `Qwen/Qwen3-VL-8B-Instruct` | 텍스트·이미지·영상 |

각각 별도의 모델과 가중치입니다. [Qwen3 모델 카드](https://huggingface.co/Qwen/Qwen3-8B), [Qwen3-VL 모델 카드](https://huggingface.co/Qwen/Qwen3-VL-8B-Instruct)

**지금 만들어 둔 UI의 기본 모델 목록은 전부 텍스트 전용**이고, 실행 중인 `Qwen3-8B`도 텍스트 전용입니다. `Thinking` 옵션은 추론 모드 전환이며, VL 여부와는 별개입니다.

## 2026-10-25T05:09:38.198Z — Codex final report

- `run-dummy-training.sh`
  - 실제 DiT 학습 프로세스를 실행하는 내부 실행기입니다.
  - 종료 시 결과 폴더·학습 로그·PID를 정리합니다.
  - 보통 직접 실행하지 않습니다.

- `start-dummy-training.sh`
  - 학습 시작용 사용자 명령입니다.
  - 이전 더미 산출물이 없는지 검사·삭제한 뒤, `run-dummy-training.sh`를 백그라운드로 실행하고 PID를 기록합니다.
  - 직접 학습을 시작할 때 사용합니다.

- `gpu-watchdog.sh`
  - GPU 프로세스를 60초 주기로 검사하는 실제 감시 루프입니다.
  - 1시간 연속 유휴이면 `start-dummy-training.sh`를 호출합니다.
  - 보통 직접 실행하지 않습니다.

- `start-gpu-watchdog.sh`
  - 감시 시작용 사용자 명령입니다.
  - 이미 감시 중이면 중복 실행하지 않고, 아니면 세션과 분리된 백그라운드 감시를 띄웁니다.

즉, `run-*`과 `gpu-watchdog.sh`는 내부 본체이고, 평소에는 `start-*` 스크립트만 실행하면 됩니다.

## 2026-10-23T12:17:43.044Z — Codex final report

네. **저장된 두 순서의 `answer.json`만으로 CPU에서 조사할 수 있습니다.** 모델 추론이나 영상 디코딩을 다시 할 필요가 없습니다.

동일한 9,404개 샘플을 짝지어 다음을 비교하면 됩니다.

- **예측 일치율**: 예측 시작·종료 시각이 완전히 같은 비율, 허용 오차 이내인 비율
- **구간 일관성**: 두 예측 구간 사이의 IoU와 시작·종료 시각 차이
- **성능 일관성**: 정답 기준 IoU 변화, 순서에 따른 개선·악화 비율
- **성공 여부 일관성**: IoU 임계값별로 둘 다 성공 / 한쪽만 성공 / 둘 다 실패
- **응답 일관성**: 응답 텍스트·생성 토큰 일치율, 파싱 실패·잘림 여부 차이

데이터셋별로 집계하고, 두 예측 구간의 IoU가 낮거나 시간 차이가 큰 사례를 추릴 수도 있습니다. **정답과의 정확도와 두 예측 사이의 일관성은 별도로 측정**하면 됩니다.

## 2026-10-23T12:20:57.875Z — Codex final report

**입력 순서에 따라 예측이 상당히 달라집니다.** Qwen3-VL-8B-Instruct의 동일한 **9,404쌍**을 GPU 없이 저장된 결과로 비교했습니다.

| 데이터셋 | 샘플 수 | 예측 구간 완전 일치율¹ | 두 예측 간 평균 IoU² |
|---|---:|---:|---:|
| Charades | 3,363 | 17.69% | 0.6450 |
| ActivityNet | 4,500 | 16.87% | 0.4375 |
| QVHighlights | 1,541 | 20.70% | 0.5041 |
| **전체** | **9,404** | **17.79%** | **0.5248** |

¹ 정수 초로 반올림한 평가용 구간 기준입니다. **원문 소수점 시간까지 일치하는 비율은 10.18%**, 응답 텍스트 완전 일치율은 9.29%였습니다.  
² 정답과의 IoU가 아니라 **두 순서의 예측끼리 겹치는 정도**입니다. 파싱 실패·길이 0 이하 구간을 제외한 8,664쌍 기준입니다.

정답 IoU ≥ 0.5를 성공으로 보면:

| 결과 | 샘플 수 | 비율 |
|---|---:|---:|
| 둘 다 성공 | 3,117 | 33.15% |
| **video → query만 성공** | **1,984** | **21.10%** |
| **query → video만 성공** | **678** | **7.21%** |

즉, **28.31%에서 순서만으로 성공 여부가 바뀌었으며**, video를 먼저 넣었을 때만 성공하는 사례가 반대보다 약 **2.93배** 많았습니다. 전체 정답 기준 mIoU도 **video 먼저 49.42% → query 먼저 37.95%**로 내려갔습니다.

**데이터 연결과 수치는 맞았지만, 제가 설정한 기본 정렬이 오해를 만들었습니다.** 처음 보이는 40개가 전부 **v→q IoU 1.0, q→v IoU 0.0**인 최악의 악화 사례였습니다.

9,404쌍의 영상·예측 연결과 18,808건의 정답 IoU를 다시 계산했고, 원본과 모두 일치했습니다. 전체 성능 하락은 다음과 같습니다.

| 데이터셋 | v→q mIoU | q→v mIoU | 변화 |
|---|---:|---:|---:|
| Charades | 48.35% | 46.05% | −2.30%p |
| ActivityNet | 46.79% | 32.24% | −14.55%p |
| QVHighlights | 59.42% | 36.93% | −22.49%p |
| **전체** | **49.42%** | **37.95%** | **−11.47%p** |

전체에서 q→v가 악화된 샘플은 **42.83%**, 개선된 샘플은 **25.57%**, 정답 IoU가 같은 샘플은 **31.59%**입니다. 개선 사례가 일부 상쇄하고, Charades의 하락이 작아 전체 평균이 저렇게 나옵니다. **실패·길이 0 구간을 빼서 성능이 높게 나온 것은 아닙니다.**

- 극단적 사례 정렬에는 설명 추가

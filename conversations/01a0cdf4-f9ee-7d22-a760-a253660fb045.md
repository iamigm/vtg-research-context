ActivityNet의 오류 파일 19개는 **공개 주석에서 사용하지 않는 추가 영상**입니다. 세 데이터셋 모두 공개 주석에 필요한 영상은 누락 없이 확인됐습니다. 다만 전체 파일 검증 기준으로는 `INCOMPLETE` 표시가 남아 있습니다.

`tmux`는 시스템 설치가 아니라 기존 로컬 설치를 사용했습니다.

- 실행 래퍼: `/home/irteam/longqa-tools/bin/tmux`
- 실제 바이너리: `/home/irteam/longqa-tools/tmux-local/usr/bin/tmux`
- 실행 서버: `aivision-gm-0`
- 작업 폴더: `/data/video/MR`

`PATH`에 없어서 `command not found`가 발생합니다. 현재 터미널에서는 다음처럼 사용하면 됩니다.

```bash
export PATH="/home/irteam/longqa-tools/bin:$PATH"
tmux ls
```

**`mr-download` 세션은 작업 완료 후 자동 종료됐습니다.** 현재 남은 세션은 `longqa-download`이며, 이번 작업 기록은 아래에서 확인할 수 있습니다.

```bash
tail -50 /data/video/MR/_tools/download.log
```

## 2026-11-02T10:03:31.681Z — Codex final report

네. **zero-shot에서 같은 조건을 유지하고 요청 FPS만 2→8로 바꾼 실험이 있습니다.** [실험 보고서](/home/irteam/experiments/zero-shot/results/thinking_vs_instruct_8fps_v1/REPORT.md)

동일한 300개 샘플·프롬프트·모델별 생성 설정·입력 순서·visual token 예산으로 비교했고, 총 1,200개 응답이 완료됐습니다.

| 모델 | 입력 순서 | mIoU: 2fps → 8fps |
|---|---|---:|
| Instruct | 영상→질문 | 48.22 → 48.49 |
| Instruct | 질문→영상 | 35.88 → 36.96 |
| Thinking | 영상→질문 | 48.62 → 49.24 |
| Thinking | 질문→영상 | 47.91 → 46.43 |

mIoU는 예측 구간과 정답 구간의 교집합/합집합 비율을 샘플별로 평균한 값이며, 높을수록 좋습니다. 표는 %입니다.

다만 **실제 프레임당 공간 해상도까지 통제한 실험은 아닙니다.** visual token 예산이 고정되어 FPS 증가에 따라 해상도가 달라질 수 있고, 최대 768프레임 제한 때문에 긴 영상은 실효 FPS가 8보다 낮을 수 있습니다. 따라서 설정상 FPS만 변경한 비교는 있지만, 시간 샘플링 효과만 완전히 분리한 비교로 보기는 어렵습니다.

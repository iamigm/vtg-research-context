## 2026-10-25T10:42:12.849Z — Codex final report

**Linux + NVIDIA GPU 기준으로는 vLLM으로 Qwen 채팅 API 서버를 띄우면 됩니다.** OpenAI 호환 API를 제공하는 방식이며, Qwen 공식 문서에서도 안내합니다. [공식 문서](https://qwen.readthedocs.io/en/latest/deployment/vllm.html)

아래는 `Qwen3-8B` 실행 예시입니다. GPU 메모리가 부족하면 더 작은 모델이 필요합니다.

**1. 설치**
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -U vllm
```

**2. 서버 실행**
```bash
CUDA_VISIBLE_DEVICES=0 vllm serve Qwen/Qwen3-8B \
  --host 127.0.0.1 \
  --port 8000 \
  --max-model-len 4096 \
  --gpu-memory-utilization 0.9
```

첫 실행 시 모델을 다운로드합니다. 외부 PC에서 접속하려면 `--host 0.0.0.0`으로 바꾸고, `--api-key 원하는키`를 추가하세요.

**3. 다른 터미널에서 채팅 테스트**
```bash
curl http://localhost:8000/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "Qwen/Qwen3-8B",
    "messages": [
      {"role": "user", "content": "안녕! 한국어로 자기소개해 줘."}
    ],
    "max_tokens": 512,
    "chat_template_kwargs": {"enable_thinking": false}
  }'
```

API 키를 설정했다면 요청에 `-H "Authorization: Bearer 원하는키"`도 넣으면 됩니다.

이것은 **API 서버**입니다. 브라우저 채팅 화면까지 필요하면 Open WebUI 같은 UI를 연결해야 합니다.

사용할 **Qwen 모델명과 GPU 종류·메모리**, 그리고 **웹 채팅 화면도 필요한지** 알려주시면 환경에 맞춰 명령어를 잡아드릴게요.

사용 중인 GPU는 로그 기준 약 139.8 GiB이므로:

| 설정값 | vLLM 메모리 예산 |
|---|---:|
| `0.9` | 약 125.8 GiB |
| `0.5` | 약 69.9 GiB |

**현재 남은 메모리의 90%가 아니라 전체 메모리의 90%**라는 점이 핵심입니다. 당시 남은 메모리는 117.25 GiB인데 125.8 GiB를 요청해서 실패한 것입니다.

값을 낮춰도 모델 자체의 답변 품질은 바뀌지 않습니다. 다만 KV 캐시 공간이 줄어들어 동시에 처리할 수 있는 대화 수나 긴 문맥을 처리할 여유가 줄어들 수 있습니다.
